1. Objectives:

To design and develop a personal portfolio website using HTML, CSS, and JavaScript.


To present personal information, skills, projects, and contact details in a professional manner.

To create a responsive and user-friendly website that works on desktop, tablet, and mobile devices.

To implement smooth navigation between different sections of the website.

To display technical skills using visual skill progress bars.

To create a contact form with input validation.

To understand the practical use of HTML structure, CSS styling, and JavaScript functionality.

To provide an online platform for showcasing projects and technical abilities.

2. Tools and Techniques:

Tool / Technique

Purpose

HTML5

Creates the structure and content of the portfolio

3. Features:

1. Navigation Bar

The website contains navigation links for:

Home

About

Skills

Projects

Contact

The navigation bar remains at the top while scrolling.

2. Home Section:

Displays:

Personal name

Professional role

Short introduction

View My Projects button

3. About Section:

Provides information about the person, interests, technical knowledge, and career goal.

4. Skills Section:

Displays skills using progress bars:

HTML – 90%

CSS – 85%

JavaScript – 75%

Python – 80%

5. Projects Section:

Displays three project cards:

Portfolio Website

Student Management System

To-Do List

Each project contains a description and a View Project button.

6. Contact Form:

The user can enter:

Name

Email

Message

JavaScript checks whether all fields are filled before displaying the success message.

7. Responsive Design:

The website automatically adjusts its layout for:

Desktop

Tablet

Mobile devices

8. Hover Effects:

Buttons, navigation links, and project cards have hover effects to make the website more interactive.

9. Form Validation:

If the user submits an empty form, the website displays:

"Please fill in all the fields."

After successful submission, it displays:

"Thank you! Your message has been submitted."

4. Output:

The final output is a responsive personal portfolio website containing:
